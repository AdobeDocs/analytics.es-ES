# Planificador de migración a Web SDK

El planificador de migración de Web SDK le ayuda a planificar y ejecutar la migración de la extensión de Adobe Analytics a Adobe Experience Platform Web SDK. Lleva la migración a un único espacio de trabajo guiado dentro de la recopilación de datos de Adobe Experience Platform, para que pueda pasar de la implementación de etiquetas existente al SDK web de una manera estructurada y rastreable.

>[!AVAILABILITY]
>
>Tanto la herramienta como la documentación están en desarrollo activo. La disponibilidad de la documentación está prevista para finales de septiembre de 2026.
